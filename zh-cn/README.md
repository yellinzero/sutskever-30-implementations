# Sutskever 30 简体中文学习版

本目录用于存放项目的完整简体中文学习版本。

翻译范围包括：

- Jupyter Notebook 的 Markdown 讲解、标题和学习提示
- Python 代码中的注释与 docstring
- 图表标题、坐标标签及其他面向学习者的展示文字
- Markdown 文档、总结和使用说明

为保证代码仍可运行，变量名、函数名、类名、第三方 API、数学公式、论文引用和数据格式保持不变。专业术语第一次出现时通常采用“中文（English）”形式。

包含图表的 Notebook 会配置常见中文字体回退列表。在 macOS 上优先使用苹方（PingFang SC）；如果图中文字显示为方框，请安装任意一种常见中文字体，如 Noto Sans CJK SC。

> 这是非官方中文学习译本，仅用于个人学习。原项目、代码及相关内容的权利归原作者所有；请以仓库根目录中的英文原文为准。

翻译状态见 [TRANSLATION_PROGRESS.md](TRANSLATION_PROGRESS.md)。
